📌 先说清楚这份计划为什么长这样

1. 旧计划作废。《嵌入式系统学习计划_14 天》按日历走完了（9/24–10/07），实际只走到 Day5（9/29），之后空置 9 天。它的节奏是"每天 1–2 小时、14 天铺开"，与你现在的条件（每天 8 小时、3 天打完）不匹配 —— 保留作参考，不再当作执行文件。

2. 24 小时装不下"学完一门课"，只装得下"面试能应答"。所以本计划按 JD 频次 × 你的水位 排序，只补"高频 + 你现在最空"的六块，其余主动放弃（见下方取舍表）。

4. 每天固定动作：学完 → 跟我说「今天读完了，来考」→ 我逐题判卷 + 记错题 + 给记忆锚 → 落库推云端。每张 Day 卡片底部的橙框就是当天考核清单。

⏱ 时间块

时段内容怎么做（产出即验收）
13:30–15:00总线 ①
UART + I2C		UART：把波特率 / 起始位 / 数据位 / 校验 / 停止位 六个要素逐个说清"为什么必须这样"；I2C：两句收口 —— 开漏只能拉低、高电平靠外部上拉；第 9 个时钟 = ACK/NACK。
产出 手画一张 UART 发一个字节的电平时序（起始位到停止位）
15:00–16:30总线 ②
SPI + CAN		SPI：四线（SCK/MOSI/MISO/CS）、CS 拉低才听你说话、高电平时从机高阻态。
CAN：只求"能讲 90 秒"—— 差分传输 + 多主 + ID 仲裁（ID 越小优先级越高，非破坏性仲裁）。
产出 CAN 的 90 秒口述稿（写下来，待会考）
16:30–17:30总线 ③
合表 + 选型		挡住材料默写四总线全表：同步性 / 双工 / 线数 / 速度 / 怎么选中对端 / 典型用途。再练三个场景选型（引脚紧张慢速 → I2C；几十 M 吞吐 → SPI；板间一米调试 → UART）。
产出 默写全表 + 一句话解释「为什么 SPI 多挂一个从机就多一根线，I2C 不用」
17:30–18:30晚饭 + 休息（不动脑）
18:30–20:30RTOS ①
任务与调度		四态转换图（就绪 / 运行 / 阻塞 / 挂起）要能自己画出来；抢占式 vs 时间片轮转的区别；上下文切换保存了什么。
产出 手画四态图 + 说清"任务从运行态会去哪儿、靠什么触发"
20:30–22:00RTOS ②
优先级反转		完整因果链（高任务等锁 → 中任务抢占 → 高任务被中任务无限延后）+ 至少两种方案（优先级继承 / 优先级天花板）。
产出 能连讲三层因果，不卡壳

✂️ 取舍表：24 小时里什么学、什么不学 最重要的一页

⚠️ 不做取舍 = 什么都学不完。下面这张表是本计划的核心决策 —— 凡是"不学"的，被问到就用话术承认 + 转走，别硬答。
判定内容理由 / 做到什么程度
死磕四总线对比 + UART/I2C/SPI 细节JD 高频 × 你水位 15 —— 必须闭卷口述全表，这是嵌入式"脸面题"，答不上直接掉档
死磕RTOS：调度 / 优先级反转 / 信号量 vs 互斥锁 / 任务通信JD 极高 × 你水位 20 —— 成都这批岗 80% 点名 RTOS，五题必须全过
死磕MCU 四题 + 中断两题一天能扫完的"常识题"，性价比极高，各 60 秒能讲
够用就行CAN无实战 → 只求"能讲 90 秒"（差分 / 多主 / ID 仲裁）。别死磕协议栈、帧格式细节、位时序计算
一句话量级Keil / IAR / 示波器 / 逻辑分析仪 / JTAG知道这工具干什么用的即可，不装会。被问就说"没用过，但我知道它是用来…"
只保温C 语言 13 题你已经 85 分，不重学，只在 Day3 乱序抽查防遗忘（"连错两天"的三条坑已焊死，但要盯保温度）
放弃Linux 内核驱动深挖（驱动模型 / 设备树语法 / 内核子系统）三天补不出实战深度。只到"能说清驱动分层"（用户态 → 系统调用 → 驱动 → 硬件），深问就承认没做过
放弃RTOS 源码级（调度器源码 / 移植 / 内存算法）面试官不会期望一个转岗的人讲到这层；真被问到，用"了解原理但没读过源码"诚实带过
放弃硬件电路 / PCB / 射频 / FPGA不属于你的方向，简历里也没写，不碰
放弃按教材顺序啃完某本书你现在要的是"能应答"，不是"学完一门课"

🚨 三条铁律（这比知识问题更要命） 贴在显示器上

  • ① 交卷前数一遍"题目里有几个问号，我答了几个"。Day4 手撕段你曾连续 4 次只交一半（memcpy 只写判空、count_one 只写一种方法、大小端只写第一问、环形缓冲三问全没答）。面试里漏答一半 = 直接判不合格。
  • ② 合上材料能口述才算会。"看过"不算 —— 这个坑已经踩过两次。所以每一步都要有"默写 / 出声讲"的动作。
  • ③ 凡有"两个兄弟"的知识点，一律做对比表。你的核心问题不是学得少，是相近概念容易串（错的几乎全是"说反"类）。固定清单：野/悬空/泄漏 · 大端/小端 · 栈/堆 · const 左/右 · volatile/atomic · 进程/线程 · 信号量/互斥锁 · UART/I2C/SPI/CAN · 推挽/开漏 · 中断/异常。
