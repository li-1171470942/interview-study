C2 · robots.txt 已设，但它挡不住什么

仓库里有 robots.txt：User-agent: * / Disallow: /。它能挡搜索引擎收录，但——

  • 挡不住知道 URL 的人直接打开链接；
  • 挡不住 GitHub 仓库页本身：github.com/li-1171470942/interview-study 任何人可浏览、可搜、可 fork、可看提交历史；
  • 所以 robots.txt ≠ 隐私方案，它只是"请勿收录"的君子协定。
