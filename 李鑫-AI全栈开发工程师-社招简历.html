② C 算法库与上层服务双向调用架构 　接口设计 / 核心开发
2024.01 – 2024.12
C 语言函数指针回调机制node-ffi内存管理性能压测
核心算法以 C 语言实现并编译为动态库，上层服务需高频调用。原有"一次性输入输出"模式在大批量数据场景下包体过大、频繁触发内存溢出（OOM），无法承载现网规模。
  • 接口架构设计：参与设计 C 算法库与上层服务的双向调用架构，将大数据量场景由"一次性输入输出"改造为分片传输 + 回调返回，从根因上解决 OOM。
  • 函数指针映射表：因 FFI 不支持异步，设计函数名 → 函数指针的映射表与初始化注册机制，把上层可调用函数注册给 C 侧、函数指针固化为全局变量，实现 C → 上层方向的主动回调。
  • 回调协议：设计 method–data–callback 三段式调用协议，支持异步返回与嵌套调用（回调中再发起调用），保证多层算法组合下的调用链正确性。
  • 内存管理：明确跨语言边界的内存归属与释放责任，避免重复释放与悬空引用；结合压测定位内存增长点。
项目成果
  • 支撑 10 万/s 调用量的压力测试，大数据量场景 OOM 问题解决，为后续规模化奠定底层能力。
  • 该接口层成为算法侧与业务侧解耦的稳定边界，新增算法无需改动上层业务代码。
