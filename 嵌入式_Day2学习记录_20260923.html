2 ⭐ 错题纸（分类整理 · 睡前逐条过）

① 指针 / 内存（6 条）

  1. malloc 的 void* 在 C 中不需要强转（C++ 才必须）
  2. malloc 不清零（内容是垃圾）；要清零用 calloc 或 memset
  3. 内存泄漏 4 场景：早 return 漏释放 / 忘析构 / 指针被覆盖丢失引用 / 循环里持续申请
  4. 野指针 = 地址随机（未初始化），≠ 内存泄漏
  5. 悬空指针 = 内存已 free、指针还留着旧地址（未置 NULL）
  6. 记忆锚：泄漏 = 钱没还钥匙丢了；悬空 = 房退了钥匙还在手里

② 对齐 / 位运算（4 条）

  1. 结构体总大小 = 最大基础成员类型的整数倍
  2. #pragma pack(1) 的代价 = 非对齐访问变慢（某些平台直接异常）
  3. C 语言没有"逻辑异或"（^ 是按位异或；逻辑运算只有 && || !）
  4. 右移：无符号补 0；有符号补符号位（实现定义，别依赖）

③ 大小端（3 条）

  1. 大端 = 高字节存低地址；小端 = 低字节存低地址（口诀：谁在前面谁住低地址）
  2. union 判断法：union { int i; char c; } u; u.i = 1; u.c == 1 → 小端
  3. 网络字节序 = 大端；主机序通常小端 → 跨平台要 htons/ntohl 转换

④ volatile（3 条）

  1. volatile ≠ 线程安全（只保证可见性，不保证原子性 → 要 atomic 或锁）
  2. 最经典场景是 ISR 共享变量（中断改、主循环读）＋ 硬件寄存器 ＋ 多线程共享标志
  3. const volatile = 程序只读、硬件会改（只读状态寄存器）

⑤ 其他（4 条）

  1. static 局部变量在程序启动时初始化（只初始化一次，之后一直存在）
  2. 数组名不是左值（不可赋值、不能 a++；C++ 里称"不可修改左值"）
  3. 数组作形参退化为指针 → sizeof 失效（所以必须另传长度）
  4. ISR 禁止阻塞 / 带锁函数、禁止 malloc/printf（不可重入）
