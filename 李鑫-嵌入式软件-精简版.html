① C 动态库跨语言调用架构设计与内存治理 　C 侧接口设计 / 核心开发
2024.01 – 2024.12
C 语言函数指针内存所有权动态库 .so数据分片回调协议性能压测
现网调优算法以 C 实现并封装为动态库（.so），由上层服务跨语言调用。原实现采用"一次性输入输出"（单次大数组传参），在万级设备批量调优时内存峰值过高、频繁 OOM，成为系统规模化的性能瓶颈。
  • 接口与数据分片设计：重新设计 C ↔ 上层调用接口，把"单次大数组传参"改造为定长缓冲区 + 分片传输 + 回调返回，内存峰值由 O(n) 降为 O(chunk)，从根因消除 OOM。
  • C → 上层反向调用（函数指针注册表）：跨语言调用层不支持异步，设计「函数名 → 函数指针」映射表与初始化注册机制，把上层回调函数注册给 C 侧、指针固化为全局函数指针表，实现 C 主动回调上层（等价于 C 侧依赖注入）。
  • 异步回调协议 + 内存所有权模型：设计 method–data–callback 三段式协议承载异步返回与嵌套调用；明确跨语言边界两侧的内存归属与释放责任（谁分配谁释放），杜绝重复释放与悬空引用。
  • 动态库构建：基于 gcc（-fPIC / -shared）将 C 算法库编译为共享库（.so），管理符号导出与头文件接口，保证上层调用侧 ABI 稳定。
成果：支撑 10 万/s 调用量压力测试，解决大数据量场景 OOM；接口层成为算法侧与业务侧的稳定解耦边界。
