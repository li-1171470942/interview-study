1 ⭐ 该学清单（按 ROI 排序 · 已对照实际目录）

第一优先：C++ 板块的「内存管理」整章（7 篇）— 直接命中你的薄弱点

卡码小节对你的价值
什么是内存泄漏？什么是野指针？内存越界？如何避免靶向 正是你 连续两天翻车的"指针三兄弟"，看它的标准表述后再做对比表
内存碎片与内存溢出 / 如何避免内存碎片靶向 补你 Q7 漏掉的"碎片化"，也是嵌入式长期运行系统的核心痛点
C++ 内存分区、堆和栈的区别巩固 对应你的 Q7，顺便复习内存五分区（Day1 已学）
new 和 malloc 的区别 / free 和 delete 的区别巩固 对应 Q8（C 岗只考 malloc/free 侧，C++ 侧了解即可）

第二优先：C++ 板块的「基础与语法」精读 6 篇（其余跳过）

卡码小节对你的价值
volatile 关键字的作用必看 补你 Q4 缺的"场景"（注意：C 岗要往硬件寄存器/ISR 上讲，不只多线程）
static 关键字和 const 关键字的作用巩固 Q5/Q6 已过，用它交叉验证
inline 函数与宏的区别与优劣补缺 直接覆盖你未学的 Q12（宏 vs 函数）
sizeof 和 strlen 的区别补缺 覆盖你未学的 Q13
结构体与联合体的区别必看 嵌入式高频！union 是"判断大小端"的经典实现（你今天错的大小端正好用得上）
静态局部变量、全局变量、局部变量的特点巩固 对应 Q6 static 的"存哪个区、默认值、初始化时机"

第三优先：计算机基础「操作系统」（除"其他"小节）

卡码小节对你的价值
中断与异常（3 问：什么是中断异常 / 区别 / 中断处理流程）必看 嵌入式最核心考点，且你明天就要学中断——先用它打底
基础概念（进程 vs 线程 / IPC / 调度算法 / 用户态内核态）必看 Q33/Q34 的答案库，你后端出身有优势，快速过
同步与互斥（同步方式 / 典型锁 / 进程同步互斥）重点 与 RTOS 的信号量/互斥锁直接相通（Q21）
内存管理（虚拟内存 / 分页分段 / 页面置换）看 有 MMU 的嵌入式平台会问；也帮你理解"进程地址空间"
I/O 与设备管理（I/O 控制方式 / IO 模型 / 磁盘调度）选看 I/O 控制方式（轮询/中断/DMA）与嵌入式高度相关，其余略读
死锁（原因 / 避免 / 银行家算法）看 概念题，10 分钟能过

第四优先：计算机组成原理（只有 2 问，但极高频）

冯·诺依曼体系结构 vs 哈佛体系结构必看 嵌入式经典题（哈佛结构=程序与数据分开存储，多数 MCU/DSP 用哈佛）
CPU 和 GPU 的主要区别可跳 与岗位无关，扫一眼即可

第五优先：网络（TCP 部分，你的强项 → 快速过 + 练口述）

TCP/UDP 区别 · 三次握手 · 四次挥手 · TIME_WAIT · 可靠性 · 拥塞控制巩固 你做过 802.11/TCP-IP 三年，这里的目标是"能口述清楚"而不是"重新学"；车载以太网同源
HTTP / HTTPS / 缓存 / Cookie / Session / DNS跳过 Web 专用，嵌入式基本不问

2 ❌ 该跳清单（省下你 60% 的时间）

板块为什么跳
数据库整章（SQL / 索引 / B+树 / MVCC / 锁 / 执行引擎 / 日志）嵌入式面试基本不考（你之前投 Java/银行岗才需要，现在可以放）
Redis 全部 8 篇同上。⚠️ 但一个例外：若被问"你后端项目里的缓存/锁"，用你 RRM 的实战回答即可，不用背八股
C++ 板块：智能指针 / 现代 C++（11 篇）/ STL 容器（8 篇）C 语言岗位不问；除非 JD 明确要求 C++
C++ 板块：面向对象大部分（构造析构/重载重写/多重继承/单例）只留 "虚函数怎么实现的"（你 Day1 学过，知道虚表是函数指针数组即可）
C++ 板块：并发与 I/O 的 select/poll/epoll偏 Linux 应用层；但 "互斥锁 vs 自旋锁"可看（与 RTOS 相通）
Java / Go / 大模型板块与岗位完全无关

4 📅 建议的复习顺序（结合你当前进度）

  1. 补 C++ 板块「内存管理」+「基础与语法」6 篇（约 2 小时）——直接治你的薄弱点：指针三兄弟、碎片化、volatile 场景、宏 vs 内联、sizeof vs strlen、结构体 vs 联合体
  2. 操作系统「中断与异常」3 篇（30 分钟）——为接下来学中断打底
  3. 我们自己的嵌入式 36 题：中断 4 → RTOS 5 → 总线 5 → MCU 5 → Linux 4（主战场）
  4. 组成原理 2 问（10 分钟）：冯诺依曼 vs 哈佛
  5. 网络 TCP 部分：只做"口述复述"（你有底子，目标是讲清楚）
  6. 操作系统其余章节：进程线程/IPC/锁/内存管理/I/O（穿插在空档）
⚠️ 别按卡码笔记的顺序从头看到尾——它的默认顺序是给互联网后端岗设计的，你会把时间浪费在数据库和 Redis 上。
