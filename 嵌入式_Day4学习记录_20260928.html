2 ✍️ 手撕代码 · 第 1 道（字符串反转）

❌ 他直接说"我还真不会这个" → 已完整讲解，明天重考（不看答案手写）。这不是"复习"，是从零建立手撕能力。

思路（面试第一句就要说）

"两个指针，一个指头、一个指尾，交换内容后向中间夹逼，直到 i 不小于 j。全程原地，不申请新空间。"

参考实现

void reverse_str(char *s) {
    if (s == NULL) return;          /* ① 先判空 —— 加分项 */
    int i = 0, j = (int)strlen(s) - 1;
    while (i < j) {                 /* ② 相遇即停 */
        char t = s[i];              /* ③ 三步交换 */
        s[i] = s[j];
        s[j] = t;
        i++; j--;
    }
}
⚠️ 经典坑（面试官爱问）：j 必须用 有符号 int 接。若写成 size_t j = strlen(s) - 1; —— 空串时 strlen=0，0-1 在无符号下变成 SIZE_MAX，i < j 成立 → 直接越界崩溃。用 int 时 0-1=-1，循环天然不执行 ✅。
✅ 四维判分标准（明天照这个自查）：① 能否编译 ② 边界（空指针 / 空串 / 单字符）③ 是否真原地（偷偷开数组即扣分）④ 面试加分（先判空 + 主动说边界）。
锚：两手从两端往中间走，见面就散。

3 ⭐ 错题纸更新（累计 21 → 25 条）

🔴 今日新增（4 条）

条目要点与根治锚
把 \0 和「退化」焊死\0 管"数到哪停"（strlen 的终止符）；退化管"你是谁"（数组名在函数参数/表达式里变指针）。两条独立规则，不在一个维度。没有 \0 的后果是 strlen 越界往下读（未定义行为），不是退化。
锚：\0 管停，退化管形。
const 判断参照物错判断"左锁值 / 右锁指针"时，看的是 * 不是变量名。const char *p 和 char * const p 里 const 都在变量名左侧，但相对 * 一左一右。
锚：盯 *，谁离它近谁先被锁；两个 const = 全锁。
static 初始化时刻不是"编译期执行"，而是：编译器把常量初值编进目标文件的 .data 段，程序启动时（main 之前）由加载器一次性载入内存。它从不是一条运行时赋值语句，所以不存在"第二次执行"。
面试标准答法："启动时一次性初始化"。
"栈为什么快"答成物理属性问"为什么快"永远问的是操作成本，不是"栈小/连续"。栈 = sub rsp 一条指令（挪指针）；堆 = 加锁 + 遍历空闲链表 + 可能分裂 + 可能 brk/mmap 进内核。
锚：栈是挪门牌号，堆是查表+记账+可能要跟内核申请。

条目要点
结构体 vs 联合体 + 对齐手算对齐两规则：① 成员偏移 = 自身大小的整数倍 ② 总大小 = 最大成员的整数倍。

4 🎯 本日生效的「操作型记忆锚」

知识点操作型锚（照着做）自检法
const 锁谁盯 *：左锁值（*p 不能改）、右锁指针（p 不能改）、左右各一个 → 全锁反推一行：p="x" 能过说明指针自由；*p='x' 报错说明值被锁
\0 vs 退化\0 管停（strlen 的刹车），退化管形（数组变指针）问"这是终止符问题，还是类型问题？"
栈 / 堆快慢栈 = 挪指针（一条指令）；堆 = 查链表 + 记账 + 可能进内核别答"大小/连续性"，那是属性不是成本
结构体对齐成员按自身大小对齐，整体按最大成员凑；从大到小排最省char;double;char → 24；double;char;char → 16
函数指针判断(*名) = 指针；名( = 函数int (*f)(int) 是变量；int *g(int) 是函数
🎤 可直接说的面试话术
· const："const 看它贴近 * 哪一侧：左边锁值、右边锁指针；const char * const p 两边都有就是全锁。"
· 栈堆："栈分配就是移动栈指针一条指令；堆要加锁、遍历空闲链表、可能还有系统调用进内核，所以慢几个数量级。"
· 项目："C 侧维护「方法名 → 函数指针」映射表，配 method/data/callback 协议，用 void* 做类型擦除，结果是异步回调不阻塞 Node 事件循环，新增方法只在表里加一行，压测到 10 万/s。"
