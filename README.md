## 使用说明

- 整个文件夹保持相对路径拷贝，打开 `学习中心.html` 即可全部跳转
- 复习计划/跟踪表的勾选进度通过页面顶部「导出进度 / 导入进度」跨电脑迁移
- 面试/求职复盘记录统一更新 `求职复习进度中枢.md`

## 备份周期

本地为主，GitHub 私有仓库作为异地备份；每次资料大版本更新后 `git add -A && git commit && git push`。
