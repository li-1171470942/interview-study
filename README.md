## 使用说明

- 整个文件夹保持相对路径拷贝，打开 `学习中心.html` 即可全部跳转
- 在线版可直接在手机 / 任意电脑打开
- 计划与记录页内的勾选进度，通过页面顶部「导出进度 / 导入进度」跨电脑迁移
- **每日学习闭环**：读（点开计划里的直达链接）→ 考（合上材料让 AI 出题判卷）→ 记（落库当日 Day 记录 → 推云端 → 隔日回炉）
