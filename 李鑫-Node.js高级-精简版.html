  • 接口架构：参与设计 C 算法库与 Node.js 的双向调用架构，将大数据量场景改造为分片传输 + 回调返回，从根因解决 OOM。
  • 函数指针映射表：因 FFI 不支持异步，设计函数名 → 函数指针的映射表与初始化注册机制，把 JS 侧可调用函数注册给 C 侧、指针固化为全局变量，实现 C → JS 主动回调。
  • 回调协议与内存管理：设计 method–data–callback 三段式协议支持异步返回与嵌套调用；明确跨语言边界的内存归属与释放责任，避免重复释放与悬空引用。
成果：支撑 10 万/s 调用量压力测试，解决大数据量场景 OOM；接口层成为算法侧与业务侧的稳定解耦边界。
