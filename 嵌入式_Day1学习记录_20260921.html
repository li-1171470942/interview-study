组一 · 指针与数组

知识点核心结论
指针算术的步长步长 = 它指向的类型的大小。a+1 走 4 字节（int*），&a+1 走 20 字节（int(*)[5]）。a 与 &a 值相同、类型不同。
数组指针 vs 指针数组int (*p)[5] = 数组指针（p 先碰 *）；int *p[5] = 指针数组（p 先碰 []）。看 p 先和谁结合。
反向取最后元素(&a)[1][-1] / *((int*)(&a+1) - 1) → 都是 a[4]。原理：&a+1 跨 20 字节，回退用 int* 的 4 字节步长。
数组名是地址常量a+1 ✅ 合法（只取值）；a++ / ++a / a=b ❌ 非法（要修改自身）。左值问题。
数组指针 vs 二级指针int(*)[5] 一级跳转、步长 20；int** 两级跳转、步长 8。前者指向一堆数据，后者指向一个地址。int **q = &a; 编译报错。
指针大小与平台有关，与类型无关：32 位 4 字节、64 位 8 字节。理由是"地址总线宽度"，不是"因为 int 是 4 字节"。

组二 · 类型与底层实现

知识点核心结论
不定长字符串输入用指针数组 char *argv[N] + 每段独立 malloc；或整行读入后 strtok_r 原地切分（0 次额外分配）。不能用 char[N][M] —— M 按最长取会浪费。
argv 为什么是 char**各参数字符串长度不一，char(*)[N] 要求等长做不到。真实模型 = 一块连续内存 + 一个指针数组索引。
_Bool 是关键字_Bool 是 C99 语言关键字；bool/true/false 才是 <stdbool.h> 里的宏。特殊语义：赋非零值会被归一化为 1（_Bool b = 5; → 1）。
定宽类型用 typedefint32_t 等是 typedef 实现，不是 #define（define 是文本替换，会出 UINT32 *p, q; 的坑）。映射到哪个基本类型由平台决定。
float→int 是截断int i = 3.9; → 3，不四舍五入（向零取整，-3.9 → -3）。要四舍五入用 round()。rint() 默认是银行家舍入（rint(2.5)=2，round(2.5)=3）。
long 跨平台差异Linux x86-64（LP64）long=8 字节；Windows x64（LLP64）long=4 字节。跨平台 bug 经典来源 → 用 <stdint.h>。

组三 · OOP 与虚函数

知识点核心结论
C 模拟对象struct 里塞函数指针当成员函数，显式传 self（= C++ 的隐式 this）。
C 实现多态struct 里放 const Vtbl *vptr，虚表放只读数据段。把父类结构体作为子类的第一个成员实现"继承" → 地址相同可安全互转，这就是 C++ 单继承向上转型零开销的原因。
struct vs classC++ 里只差两个默认值：默认访问权限（public / private）、默认继承方式（public / private）。其他完全等价。
虚函数三问虚表在只读数据段（每类一张，编译期生成）；vptr 在对象里（8 字节，通常在起始处）；vptr 在构造函数里设置。
虚函数陷阱① 基类析构必须虚（否则 delete 泄漏）② 构造/析构里调虚函数不多态 ③ 默认参数静态绑定 + 函数体动态绑定（b->f() 输出基类默认值！）
名词全称MCU = Microcontroller Unit（微控制器）；MPU = Microprocessor Unit；SoC = System on Chip；OOP = Object-Oriented Programming；RTOS / HAL / BSP。
